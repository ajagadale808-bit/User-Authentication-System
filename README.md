# User Authentication System

A web-based User Authentication System built using Node.js, Express.js and MongoDB.

## Features
- User Registration
- User Login
- Password Hashing using bcryptjs
- JWT Authentication
- Protected Dashboard
- Logout Functionality

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs

## Installation

1. Clone or download the project.
2. Install dependencies:

   npm install

3. Create a .env file and configure:

   PORT=5000
   MONGO_URI=your_mongodb_connection_string
   JWT_SECRET=your_secret_key

4. Start the server:

   npm start

5. Open in browser:

   http://localhost:5000/register.html
